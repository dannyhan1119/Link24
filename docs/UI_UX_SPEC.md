# Link24 界面与交互规范

版本：0.1  
目标画布：1080×1920 竖屏  
实现方式：Godot `Control` 系统与响应式锚点

> 视觉风格仍然有效，但局内结构正在按 [绿洲迁徙新方案](GDD_MIGRATION.md) 重构。原 5×5 固定棋盘线框不再是最终布局；新的局内界面需要支持大地图、镜头移动、雾气、小地图、动物队伍与道路网络。

## 1. 视觉方向

采用原创的现代休闲益智风格：

- 高明度天空蓝与暖白背景。
- 大圆角卡片和软塑料按钮。
- 轻微立体阴影，避免过度拟物。
- 大数字、高对比和充足留白。
- 云朵、气泡、圆点等低信息量背景装饰。
- 棋盘始终是画面视觉主体。

概念参考图：

[link24-ui-concept-v1.png](design/link24-ui-concept-v1.png)

### 已确认的视觉基准

`link24-ui-concept-v1.png` 是最终成型效果的主要视觉目标。Godot 实现应尽量还原其中已经确认的：

- 明亮的天空蓝与暖白背景。
- 云朵、气泡和圆形装饰构成的轻快氛围。
- 珍珠白数字块、柔和高光、彩色边缘与软阴影。
- 大尺寸目标环和清晰的数字层级。
- 圆润、轻微立体的底部操作按钮。
- 现代休闲游戏的精致感和奖励感。

概念图不是需要逐像素复制的静态贴图；不同屏幕比例、交互状态和动态效果仍按本规范进行响应式实现。

`wireframes/gameplay.svg` 只定义区域划分、信息顺序、触控范围和交互关系，不代表最终颜色、材质或美术完成度。当线框与概念图的视觉表现发生冲突时：

1. 布局和可用性以本规范及线框为准。
2. 色彩、材质、造型和整体观感以概念图为准。

## 2. 色彩语义

| 用途 | 建议颜色 | 说明 |
|---|---|---|
| 背景天空 | `#51C7F4` | 明亮但不抢数字 |
| 背景暖白 | `#FFF8E8` | 承托棋盘 |
| 普通格面 | `#FFFDF7` | 所有普通数字统一 |
| 普通数字 | `#18304F` | 深蓝黑，高可读性 |
| 当前路径 | `#28C8E8` | 青蓝色 |
| 恰好 24 | `#44D38A` | 成功绿 |
| 超过目标 | `#FF6F6A` | 珊瑚红 |
| 提示 | `#FFBE3D` | 暖黄色 |
| 次要信息 | `#66809C` | 降低层级 |
| 障碍 | `#B9C8D8` | 同时配合图案 |

颜色不能单独承担信息。成功、超额和障碍状态还要配合图标、轮廓、动画或文字。

## 3. 字体

- 数字使用圆润但不变形的粗体无衬线字体。
- 中文使用清晰的现代黑体。
- 数字格中的数字必须使用等宽或视觉宽度稳定的字形。
- 不使用描边厚重的卡通字体。
- 最小正文在 1080×1920 画布中不低于 32px。

建议层级：

| 内容 | 参考字号 |
|---|---:|
| 当前累计值 | 88～108px |
| 数字格 | 64～82px |
| 关卡标题 | 42～50px |
| 目标进度 | 38～46px |
| 辅助提示 | 32～38px |

## 4. 局内布局

线框文件：

[gameplay.svg](wireframes/gameplay.svg)

由上到下分为五个区域：

### A. 顶部状态栏

- 左侧：`第 7 关`。
- 中间：主目标进度 `2 / 4`。
- 右侧：设置或暂停。
- 不在这里堆叠金币、体力、星星等无关信息。

### B. 目标环

- 主数字显示 `17 / 24`。
- 次级文案显示 `还差 7`、`刚好！`或`超过 3`。
- 环形进度只表现 0～24，不承担关卡完成进度。
- 达到 24 时由青蓝过渡到绿色。

### C. 棋盘

- 5×5 为默认尺寸。
- 棋盘宽度约为画布宽度的 88%。
- 格子间距约为格子边长的 8%。
- 触摸热区比可见格子四周扩大，但不能与相邻格严重重叠。
- 路径绘制在格子下方，连接节点绘制在格子中心。
- 当前选中格上浮并轻微放大。

### D. 算式条

- 显示当前路径：`6 + 6 + 5 = 17`。
- 路径过长时保留首尾数字并使用省略号。
- 空闲状态显示短提示：`连接相邻数字，凑成 24`。
- 不使用阻断棋盘的浮动弹窗。

### E. 底部操作栏

- 重置、撤销、提示三个按钮。
- 图标下可在首次使用时显示文字标签。
- 提示按钮必须显示剩余次数或观看条件。
- 按钮点击区至少为 96×96 设计像素。
- 底部保留系统手势安全区。

## 5. 输入状态

### Idle

- 目标环显示 `0 / 24`。
- 棋盘可交互。
- 算式条显示玩法提示。

### DraggingValid

- 选中格放大至约 1.08。
- 路径为青蓝色。
- 目标环、算式和“还差”同步更新。
- 每进入新格播放一次极短音效。

### DraggingExact

- 目标环转为绿色。
- 文案显示`刚好！松手完成`。
- 路径出现一次短促亮度脉冲。
- 触觉反馈只触发一次。

### DraggingOver

- 目标环和最后一段路径转为珊瑚红。
- 文案显示`超过 3，向后拖动可撤回`。
- 禁止继续向新格扩展。
- 允许拖回前一格修正。

### DraggingIllegal

- 非法目标格显示禁用轮廓。
- 路径不延伸。
- 不弹出错误对话框。

### Resolving

- 暂停新的按下输入约 150～250ms。
- 路径中的数字依次缩小消失。
- 进度粒子飞向顶部 `2 / 4`。
- 棋盘稳定后立即重新开放输入。

### NoSolution

- 棋盘轻微降亮。
- 显示非阻断提示：`当前没有可用组合`。
- 强调“撤销”或“重置”按钮。
- 不让玩家继续无目的寻找。

## 6. 动画时长

| 动画 | 时长 |
|---|---:|
| 格子按下 | 70ms |
| 路径吸附 | 60～100ms |
| 达到 24 脉冲 | 140ms |
| 非法抖动 | 160～200ms |
| 单格消失 | 120ms |
| 路径消失间隔 | 30～40ms |
| 目标进度增加 | 180～240ms |
| 结算面板进入 | 280～350ms |

所有高频动画应可中断。开启“减少动态效果”后，位移和缩放幅度至少降低 60%。

## 7. 手指遮挡处理

- 累计值始终在目标环中显示。
- 拖动时在触点上方约 110px 显示一个小型累计气泡。
- 气泡根据手指靠近屏幕边缘自动换侧。
- 连接判定使用格子中心吸附，不要求手指精确经过中心。
- 进入相邻格达到约 35% 覆盖即可吸附。

## 8. 关卡选择

使用一条轻量的“沙漠迁徙”路径：

- 每个关卡节点显示编号和完成状态。
- 当前可玩节点尺寸稍大。
- 锁定节点降低饱和度，但仍可预览后续主题。
- 每 10 关形成一个短章节。
- 不使用三颗意义不清的星星。
- 挑战徽章只在条件已经向玩家公开时显示。
- 已解锁段使用连续草地路线，锁定段使用低饱和雾化虚线。
- 当前节点使用缓慢呼吸高光，已解锁路线可显示低频流动光点。

章节地图复用局内沙漠、绿洲、动物与障碍资源，不额外引入城堡或复杂剧情地图。

## 9. 结算

信息顺序：

1. `完成！`
2. 本关关键结果。
3. 挑战徽章是否达成。
4. `下一关`主按钮。
5. `重玩`和`返回关卡`次按钮。

结算动画总时长不应阻止玩家在一秒内点击下一关。

## 10. 可访问性

- 支持减少动态效果。
- 支持关闭震动和声音。
- 状态不只依赖红绿颜色。
- 关键按钮提供明确的按下态。
- 所有文本预留简体中文和英文长度差异。
- 屏幕宽高比变化时优先保证棋盘、目标环和底部安全区。
