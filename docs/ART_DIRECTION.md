# Link24 正式版美术方向

## 视觉基准

正式版以 [迁徙局内概念图](design/link24-migration-ui-concept-v1.png) 为主要视觉目标：

- 明亮、轻快、温暖的现代休闲游戏风格。
- 软 3D、圆润玩具感和轻微手绘质感。
- 奶油色石块、蜂蜜色沙地、鲜绿色道路与青蓝色水面。
- 角色表情友好，轮廓在手机小尺寸下仍然清楚。
- UI 使用奶油白面板、蓝色交互按钮和金色目标环。

线框图只约束信息结构与交互，不作为最终材质效果。

## 资源技术标准

- 运行时角色、绿洲与装饰物使用带 Alpha 的 PNG。
- UI 和数字保持代码/字体渲染，不能烘焙在场景图片中。
- 核心角色建议至少保留 2 倍目标显示尺寸，Godot 中向下缩放。
- 世界资源使用固定世界坐标，HUD 图标使用固定屏幕坐标。
- 小尺寸目标图标必须保留“水面 + 绿植”两个识别特征。
- 所有正式资源进入项目后都必须检查透明边缘、缩放、裁切和移动端可读性。

## 地图层级

从下到上：

1. 沙漠环境底图。
2. 环境装饰与障碍。
3. 数字石块和已开通草地道路。
4. 选中连线、提示和粒子。
5. 动物队伍。
6. 棋盘外目标绿洲。
7. 屏幕空间 HUD、小地图与边缘目标投影。

当前 HUD 已接入天空渐变、奶油色软阴影面板、正式软 3D 操作按钮、实时迁徙小地图和 24 点达成脉冲。操作按钮包含按压位移、回弹和短触觉反馈；薄雾使用连续云团覆盖并以低频率轻微漂移，新区域揭开时会分批淡出、收缩并向外散开。动物队伍具有呼吸待机和站姿、左步、右步组成的四拍行走循环，绿洲水面具有待机微动。三种障碍外观根据关卡编号和格子坐标稳定混用，减轻重复贴片感。开路反馈已使用现有砂岩与草地资源实现逐格翻转、草路生长、尘土和光点，最终迁徙路线具有持续向目标流动的高光。抵达目标后会播放绿洲扩散光环、叶片和闪光恢复效果。棋盘上下的沙漠背景已连续覆盖到两片棋盘外绿洲，草地道路改为外轮廓与内层表面双层合并绘制，避免单格贴片接缝，并加入程序化草叶与花朵细节。

第一章关卡选择页已复用正式沙漠、绿洲、动物和障碍资源。已解锁节点之间使用草地迁徙带与流动光点连接，锁定段使用低饱和雾化虚线；当前节点有呼吸高光，完成节点显示绿色确认状态。
