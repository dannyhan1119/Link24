# Contributing to Link24

Thanks for helping improve Link24. Bug reports, level-design feedback,
accessibility improvements, translations, tests, and focused code changes are
all welcome.

## Before opening a pull request

1. Open an issue first for large gameplay or architecture changes.
2. Keep each pull request focused on one problem.
3. Match the existing GDScript style and avoid unrelated formatting changes.
4. Add or update an automated test when behavior changes.
5. Run the relevant scripts listed in the README's **自动测试** section.

## Reporting bugs

Please include the Godot version, operating system or Android device, steps to
reproduce, expected behavior, actual behavior, and logs or screenshots when
available. Do not post signing keys, tokens, private save data, or other
sensitive information.

## Assets and documentation

By contributing original code, you agree to license it under the repository's
MIT License. By contributing original assets covered by `ASSETS_LICENSE.md`,
you agree to license them under CC BY 4.0. Clearly identify any third-party
material and its license in the pull request.
